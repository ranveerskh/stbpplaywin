Adult/live compatibility decision:
The synthetic v1.8.13 [PIN] 18+ Channels remapping is removed. The player
preserves the provider category and channel genre ID as v1.8.12 did. The
existing app parental PIN still protects locked provider categories and
relocks when the user leaves the category or changes mode.

Backend-first release order:
1. Deploy analytics-backend/functions/analyticsEvents.
2. Deploy Firestore rules.
3. Create admins/{uid} with role "admin".
4. Deploy the separate analytics-dashboard through Firebase Hosting.
5. Build and distribute Netplus-IPTV-Player-Setup-1.8.14.exe.

Privacy boundary:
The app sends only a random installation ID, version, platform, an
allow-listed event name, and safe metadata. The backend stores a one-way HMAC
of the installation ID. Provider credentials, portal URLs, MAC addresses,
PINs, stream URLs, channel names, raw IP addresses, and personal files are
not part of the analytics payload.
